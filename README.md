# PythonCalculator



## Eng-US
A text-based calculator built with Python. The goal is to create a program where the user inputs a low or medium-complexity operation in a single line, and the code returns the result.

## Pt-BR
Calculadora baseada em texto desenvolvida em Python. O objetivo é criar um programa no qual o usuário digita, em uma única linha, uma operação de complexidade baixa ou média, e o código retorna o seu resultado.
